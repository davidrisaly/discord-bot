# discord-bot
This project started from my ambition to merge 3 bots into single bot like this.  
Also, i wanted full control over my own bot, not like other 3rd party discord bot.  
  
And yeah, i planned (and also expected) this bot runs in a guild and small amount of member, why? because current architechture limitations.

Support for multi guild and many user handling will be there soon (if school don't go crazy).

## Features
- welcome/goodbye message (implemented)
- counting (progress)
- moderation
- leveling
- economy
